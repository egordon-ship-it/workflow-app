# Email Workflows

Dynamic Media internal app — single source of truth for email workflows
across departments (billing, operations, customer service, sales, and more).

Built on the [dm-app-starter](https://github.com/drryansantangelo/dm-app-starter)
design system (sidebar shell, tokens, UI primitives).

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## What's in this shell

- **App chrome** — fixed DM sidebar + top bar (light/dark)
- **Department dropdowns** — expand each department to see its workflows
- **All Emails** — placeholder catalog with HubSpot open affordance
- **Workflow detail** — placeholders for enrollment, timing, suppression, history, and email sequence

Real workflow logic, Word-doc email import, and HubSpot deep links come next.
